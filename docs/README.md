# Presenter pages

Long-scroll pages for presenting a session, one per lesson. Each `index.html` is a self-contained page
(Google Fonts is the only external request). The sources are in
`L3 2026 Agentic Platform Instructor Materials/lesson-pages/` (for example `01-agent-runtime.html`); `docs/lesson-NN/index.html`
is the same content wrapped in a full HTML document so it can be served by GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / `docs`).

- [Session 01: Agent architecture and the ReAct runtime](lesson-01/index.html) · [just the prompts](lesson-01-just-prompts/index.html)
- [Session 02: Reliable tools and MCP integration](lesson-02/index.html)

The prompts-only pages (`lesson-NN-just-prompts/`) are generated by
`L3 2026 Agentic Platform Instructor Materials/lesson-pages/build_prompts_page.py NN` from `LEARNER_PROMPTS.md`; rerun it when the prompts change.
