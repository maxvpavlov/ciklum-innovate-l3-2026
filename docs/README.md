# Presenter pages

Long-scroll pages for presenting a session, one per lesson. Each `index.html` is a self-contained page
(Google Fonts is the only external request). The source of the Session 01 page is
`L3 2026 Agentic Platform Instructor Materials/lesson-pages/01-agent-runtime.html`; `docs/lesson-01/index.html`
is the same content wrapped in a full HTML document so it can be served by GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / `docs`).
